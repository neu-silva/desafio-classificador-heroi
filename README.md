# Classificador de Nível de Herói

Projeto desenvolvido como desafio prático da DIO.

## Objetivo

Classificar o nível de um herói de acordo com sua quantidade de experiência (XP).

## Tecnologias e conceitos utilizados

- JavaScript
- Variáveis
- Operadores
- Estruturas de decisão (if, else if e else)
- Laço de repetição (for...of)
- Array e objetos

## Como executar

1. Tenha o Node.js instalado.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:

```bash
node index.js
```

## Exemplo de resultado

O Herói de nome Arthur está no nível de Platina.
